# CHANGELOG

## v0.2.0 — «Плавное число, магазин и невидимый софткап»

### Рост
- Главное число **растёт плавно**: между шагами умножения `N = N × M` значение интерполируется
  в логарифмическом пространстве (`G.growth.displayD / displayN`). Логика осталась дискретной —
  цифры механик не «сглаживаются», меняется только отображение.
- `growth.tick` применяет барьер к **приращению цифр** (`ΔD = log10(M)·factor`), а не к множителю.
  Иначе софткап переставал что-либо значить при огромном `M`.

### Энергия
- Новая формула: `E = 1 · (1 + D) · 1.25^lvl(energy1) · Π(energyMult)` — линейно от количества
  нулей (`D`), вместо квадратичной `(1+log10 N)²`. Скейлинг энергии сильно уменьшен.
- Добавлены **8 одноразовых «Форсажей»** (⚡ ×2 каждый) на разных этапах: 150 → 8e7 энергии.
  Они в общем списке «Рост», покупаются один раз, компенсируют линейную энергию.

### Магазин «за само число» — новая механика `shop` (🛒)
- Цена измеряется **в цифрах** (`costD`): покупка уменьшает `N` (`10^(D−цена)`), но ниже 2 цифр не опускает.
- 4 товара с лимитами:
  | Товар | Эффект | Цена (цифры) | Макс |
  |---|---|---|---|
  | Батарейка | ⚡ ×1.5^lvl | `0.30 · 1.8^lvl` | 6 |
  | Жирный плюс | `M_base += 500·lvl` | `0.80 · 1.8^lvl` | 6 |
  | Хроно-скидка | `ΔT ×= 0.95^lvl` | `1.00 · 1.9^lvl` | 8 |
  | Показатель | бонус механик `^(1.05^lvl)` | `1.00 · 1.6^lvl` | 6 |
- У каждого товара свой `minD` (8 / 18 / 30 / 70) — покупки распределены по этапам.
- Степень бонуса жёстко ограничена `MAX_EXP = 1.5` в `growth.M` — движок нельзя сломать.

### Невидимый софткап
- `G.content.hiddenSoftcap`: `factor = 1 / (1 + ((D − knee)/span)^power)`, не показывается в UI.
- Начальные значения: `knee = 5`, `span = 18.2`, `power = 1.5`.
- Применяется и к оффлайн-прогрессу (шагами по 10 цифр).
- Балансировка: `tools/sim.js` (учитывает энергию, магазин, ❖, барьер и софткап)
  даёт **1e308 за ~83 минуты** на 5 разных сидах (цель 85 ± 10).

### Прочее
- `G.fmt`/UI: цена магазина показывается как «−X.XX цифр» или «D ≥ Y».
- `upgrades.js`: поддержка цены `costD` и покупки «за число».
- `docks.js`: доска «Рост» теперь строит все `upgradesOf('core')` автоматически.
- `index.html`: добавлены скрипты `shop`, favicon-заглушка (404 исчезает).
- `tools/sim.js`: переписан под новую экономику, `REPORT`/`SEED`/`HK`/`HS`/`HP` — параметры.


## v0.1.1 — «Облачные сейвы через GitHub Gist»

- `src/systems/cloud.js`: загрузка/скачивание сейва в приватный гист GitHub.
- Токен и id гиста хранятся **отдельно от сейва** (localStorage) — не утекают в экспорт строкой.
- Кнопки: «Проверить токен» (GET /user), «Отправить» (создаёт гист при первой отправке, потом PATCH), «Скачать».
- Автосинхронизация: вкл/выкл + интервал 1/2/5/15 мин, вызывается из главного цикла (`cloud.maybeAuto`).
- Ошибки читаемые: неверный токен, нет доступа, нет связи, лимит GitHub.
- В настройках появился блок «Облако (GitHub Gist)» со статусом и ссылкой на гист.

### Версионирование и публикация
- Репозиторий на GitHub как единственный источник правды.
- `VERSION` — текущая версия, `docs/GIT.md` — инструкция, схема версий.
- Скрипты: `PUBLISH_SETUP.bat` (первый push), `PUSH_VERSION.bat` (коммит + тег + push), `GIT_STATUS.bat`.
- `README.md` — лицо репозитория, колонтитулы для GitHub Pages.
- **Исправление:** все три `.bat` переписаны — только ASCII, никаких блоков `if (...)`, `goto`-метки,
  запуск через `cmd /k call "%~f0" go` (окно не закрывается), `cd /d "%~dp0."`.
  В `docs/GIT.md` добавлен §0 — ручная публикация через PowerShell / GitHub Desktop.

## v0.1 — «Каркас + первые 3 механики» (текущая)

Первая играбельная версия для плейтеста баланса.

### Ядро
- `BigNum {m, e}` с 15 значащими цифрами, без `Infinity` в логике.
- Парсер строк-формул (`core/formula.js`) — все эффекты задаются данными.
- Реестр контента (`core/registry.js`) — движок не знает имён механик.
- Универсальный сброс по `scope: run | tier | meta`.
- Барьеры: `wall_308`, `wall_1000` (пока только сдерживают рост, БУМ в v0.5).

### Механики
- **Сумма цифр, брат** — `Σ` значащих цифр мантиссы.
- **Прайм-стайл** — количество простых цифр в мантиссе, джекпот при 15/15.
- **Простые разряды** — `❖` за каждый пройденный простой разряд `D`.

### Интерфейс
- Главное число всегда на экране, 3 позиции (сверху / снизу / только число).
- Доки слева, у каждой механики своя доска с визуалом (цифры, таймер сэмпла, лента простых разрядов).
- 3 формата чисел: короткий `124 M`, научный `1.24e8`, полный `124 000 000`.
- Тосты событий, модалка настроек, покупка кликом и зажатием.

### Сохранения
- Автосейв (интервал 5/10/30/60 с), сейв при уходе со страницы.
- Экспорт/импорт строкой, сброс, версия сейва и заготовка миграций.
- Оффлайн-прогресс: 50% эффективности, потолок 8 часов, закрытая формула.

### Не сделано (следующие версии)
- Перерождение P1 и БОЛЬШОЙ БУМ (v0.5).
- Автоматизация досок `auto1..auto3`.
- Механики «настройка мантиссы», Бенфорд, корень зла, решето, степень.
