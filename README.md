# ЧИСЛО — number incremental

[![CI](https://github.com/gnatukroma99-hash/Number-inc-testing/actions/workflows/ci.yml/badge.svg)](https://github.com/gnatukroma99-hash/Number-inc-testing/actions/workflows/ci.yml)

Браузерный **идл-инкрементал** про число, которое растёт само. Каждые `ΔT` секунд `N = N × M`.
Твои цифры — это не просто счёт: **значащие цифры** мантиссы и **порядок величины** дают бонусы
(сумма цифр, простые цифры, цифровой корень, паттерны, простые разряды).

Софткапы и локкапы **временные** — число всегда может расти дальше, ярусы масштабируются бесконечно.

## Играть

Скачай репозиторий и открой **`index.html`** двойным кликом. Сервер не нужен — работает из `file://`.

Онлайн-версия (если включён GitHub Pages): `https://<твой-логин>.github.io/<репозиторий>/`

## Управление

- **`1..9`** — доски, **`S` / `Ы`** — сохранить, **`Esc`** — закрыть настройки
- F12 → Console: `G.debug.setD(50)` — прыгнуть на 50 цифр, `G.debug.give(1e9)` — выдать энергии
- Баланс без браузера: `node tools/sim.js 120` и `node tools/bench.js 3 300`
  (bench гоняет реальный код `src/`, включая P1)

## Структура

```
index.html          точка входа (все скрипты классические, не ESM — чтобы работало из file://)
assets/css/         стили
src/core/           bignum, formula, digits, format, dom, registry, eventbus
src/systems/        state, growth, upgrades, sampling, primes, prestige, automation, save, cloud
src/content/        ДАННЫЕ: ресурсы, апгрейды, ярусы, барьеры
src/mechanics/      по папке на механику (index.js + board.js): цифры, прайм, ПРАЙМ, анализ, магазин, перерождение
src/ui/             главное число, доки, доски, настройки, тосты
tools/sim.js        симулятор баланса по формулам (node)
tools/bench.js      прогон реального кода src/ + перерождения (node)
tools/bump.js       версия одной командой: VERSION · G.VERSION · ?v= · package*.json
tools/verify.js     все проверки параллельно + один отчёт (checkall/domtest/sim/bench)
tools/layout.js     измерение раскладки в реальном Chrome (CI): прокрутка доков, высоты, стили
.github/workflows/  ci.yml — GitHub Actions: checkall → domtest → sim → bench
PUBLISH.bat         одна кнопка на релиз (бамп + тесты + коммит + тег + пуш), PULL.bat — забрать
docs/               ТЗ, ARCHITECTURE, MECHANICS, CHANGELOG, GIT
```

**Добавление механики не требует правок в `core/` и `systems/`** — это главный критерий архитектуры.
Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
